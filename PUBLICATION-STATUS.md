# Publication status

**Publication-ready research repository — version 1.0.0.**

- This repository is prepared as a public research artifact accompanying the written assignment *Reinforcement Learning for Sequential Trading Decisions: A Controlled PPO Study on State Representation and Reward Design*.
- It contains experiment code, the exact historical input dataset, configuration, dependency locks, tests, a read-only dashboard, documentation, static explanatory figures and the aggregate, per-training-start, baseline and seed-dispersion reports for VALIDATION and TEST. It does not contain day-by-day agent trajectories or portfolio replay, trained models, checkpoints, training logs or full run records.
- The dashboard renders only a reviewed evidence package produced under the Research Evidence Contract. No evidence package and no approved binding are installed, the dashboard's binding allowlist is empty, and results remain disabled pending a separately reviewed enabled consumer. The dashboard therefore shows no result value, chart or table.
- Source code is licensed under the MIT License. Original documentation, result explanations and figures are licensed under CC BY 4.0. The included Binance market dataset remains available for reproducibility but is excluded from those grants; see `LICENSE` and `data/raw/README.md`.
- Nothing here is a live trading system, financial advice, a claim of profitability or a claim of statistical significance.

Descriptive, non-inferential — not financial advice. Research use only.
